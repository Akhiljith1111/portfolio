Case study · HR management

Bloom Console

One HR console that brings onboarding, projects, timesheets, leave and tech-desk requests together.

Role
Frontend engineer
Built at
Edstem Technologies
Type
HR platform
Stack
React · Styled Components

The problem

HR work was spread across separate tools: onboarding checklists in one place, timesheets in another, and leave requests over email.

The team needed one console where every module, from the employee's first day to their weekly timesheet, felt like the same product.

What I built

Module

Employee onboarding

Guided onboarding flows so new joiners and HR can see what's done and what's pending.

Module

Projects & timesheets

Project allocation and timesheet entry in one place, ready for reporting.

Module

Leave management

Requests, approvals and a team leave calendar, replacing email threads.

Module

Tech desk

IT and tech-desk requests raised and tracked inside the same console.

Outcome

Five HR workflows brought into a single, consistent console.
  • Onboarding, projects, timesheets, leave and tech desk in one app
  • Shared styled components across every module

Tech used

ReactStyled ComponentsREST APIs

Takeaway

"Many modules, one product feel. Shared components are what make a big internal tool feel trustworthy."
