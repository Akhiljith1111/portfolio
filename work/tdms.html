Case study · HR tech · AI

TDMS

An AI-powered talent data management platform that extracts candidate details from résumés, so recruiters stop retyping.

Role
Frontend engineer
Built at
Edstem Technologies
Type
AI HR platform
Stack
React · TypeScript · Java

The problem

Recruiters spent hours copying candidate details out of résumés in every format imaginable and into their systems. The work was slow, error-prone and repetitive.

TDMS uses AI to extract and parse that data automatically. It needed an interface that made the AI's output easy to trust and act on.

What I built

AI

Résumé parsing interface

The UI for uploading résumés and turning AI-extracted data into structured candidate profiles.

Workflow

Recruitment workflows

Screens that streamline how HR teams find, manage and move candidates forward.

Frontend

Typed, maintainable UI

React with TypeScript, so a data-heavy interface stays safe to change as the product grows.

Full-stack

Java services & DevOps

I worked with the Java backend and DevOps workflows alongside the frontend.

Outcome

Recruitment data entry went from manual retyping to AI-extracted candidate profiles.
  • Résumé data captured automatically instead of retyped
  • Streamlined recruitment and data-management workflows

Tech used

ReactTypeScriptJavaAI parsingREST APIsDevOps

Takeaway

"The best AI features are quietly boring: they just make a tedious task disappear."
